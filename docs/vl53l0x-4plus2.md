# VL53L0X 紫色 4+2 排针模块

依据用户提供的原理图和尺寸照片绘制，厂商未知。类别 `3rd.module.sensor`；符号 `VL53L0X_4Plus2`；封装 `VL53L0X_4Plus2_PinHeader_P2.54mm_13x10mm_Provisional`。

顶视，VIN 位于左上，模块安装在底板上方。焊盘和符号均以功能名称作为电气编号，避免引入图片中不完整排针原理图的编号。

| 焊盘 | x / mm | y / mm |
| --- | ---: | ---: |
| VIN | -5.08 | -3.81 |
| GND | -5.08 | -1.27 |
| SCL | -5.08 | 1.27 |
| SDA | -5.08 | 3.81 |
| XSHUT | 5.08 | 1.27 |
| GPIO1 | 5.08 | 3.81 |

纵向孔距 2.54 mm。两列间距按照片比例及用户要求的整倍数取 10.16 mm（4×2.54），属于估算，需实物核对。板尺寸采用图片标称 13×10 mm，居中摆放，四角 R0.3 为近似值。板边距随居中假设估算。焊盘直径 1.8 mm、孔径 1.0 mm 为常规排针设计选择，VIN 用圆角矩形作方向标记。

模块板框画在 F.SilkS/F.Fab，底板无 Edge.Cuts。右上模块安装孔估算中心 (4,-2.4)、直径 3.2 mm，仅画 F.Fab 参考圆，**不自动给底板钻孔**。传感器外形也仅作 F.Fab 参考，不代表已经核实的光学窗口位置。功能丝印均在模块轮廓内。

依用户原理图：VIN 经板载 LDO 供电；SCL/SDA 有板载电平转换，XSHUT/GPIO1 直接连接传感器电源域。不能据此认定后两脚与 VIN 电压兼容。未臆测或标注未提供的额定电压。

符号使用 7.62 mm 引线，最长功能编号 XSHUT 的宽度按项目公式为 3.25 mm（字号 1 mm），所需引线 ceil_grid(3.25+2.54)=7.62 mm；符号宽 25.4 mm，满足两侧名称净距。引脚集合与焊盘集合一致。
