# HC-DC-044-2.5-03B DC 座

最终选型为虹成 HC-DC-044-2.5-03B，立创编号 C55014014；符号为 `3rd.connector:HongCheng_HC-DC-044-2.5-03B`，封装为 `3rd.connector:BarrelJack_DC-044_Horizontal`。本次未发布的 03A 草稿已撤下。

## 内部关系

| 编号 | 功能 | 顶视、插口朝左时的位置 |
| --- | --- | --- |
| 1 | CENTER，插头中心接点 | 下方，(10.2, 3.2) |
| 2 | SLEEVE，插头外筒接点 | 上方，(10.2, -5.3) |
| 3 | SW/NC，常闭开关脚 | 中间，(10.2, 0) |

未插入插头时 2–3 导通，插入时断开；1 与 2/3 在座内无直接连接。电路自行决定正负极。符号画出内部接点，封装丝印标出每脚功能、2–3 NC 和 PLUG: OPEN，箭头朝插口。

## 尺寸与来源

- 厂商手册：`HC-DC-044-2.5-03B-datasheet.pdf`，Rev A；前沿 x=0，本体 11.6×9.5 mm，y=-6..3.5，三个焊脚中心 x=10.2。
- 三个槽孔 2.0×0.8 mm；本库焊盘 3.0×1.6 mm，圆角半径 0.25 mm。
- 定位孔中心 (4,0)，NPTH Ø2.2 mm，按 03B 手册绘制，无 Edge.Cuts。
- 丝印避让焊盘，功能文字放在本体内部，Value 放 F.Fab；无 3D 模型。
- 编号交叉核对来源：[嘉立创 EDA](https://lceda.cn/) / [EasyEDA 官方库](https://easyeda.com/)，商品 C55014014 对应封装 UUID `bbb8346b0b954d139a75231b50438ca8`，源数据保存为 `HC-DC-044-2.5-03B-lcsc-reference.json`。该库复用名为 `DC-IN-TH_HC-DC-044-2.0-03B` 的封装；本库按 2.5-03B 的具体型号手册重新计算尺寸，不复制其全部几何。
- 原始 EDA 坐标换算每单位 0.254 mm：上方 2、中间 3、下方 1，间距分别 5.300/3.200 mm，与本型号手册一致。EDA 定位孔为 Ø2.0，本库采用手册的 Ø2.2。

按最新链接核对后，不能把机械位置居中的焊脚称为“中心针脚”：中间焊脚实际上是 3，中心针电气端为下方的 1。符号与封装编号已一致。
