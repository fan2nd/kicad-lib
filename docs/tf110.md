## 电气修正

- 手册明确：未插卡 SWA–SWB 闭合，插卡后断开。旧符号虽然写有 NC，却画了断开的触点；新符号按未插卡闭合状态绘制，并把图形连接至对应引脚。
- SWB 在手册中是检测开关端，未标为电源地。原符号的 SWB 从 power_in 改为 passive，显示名称改为 SWB；不再暗示其必须当作地端。SHELL、VSS、SWB 保持三个独立逻辑端子，是否外部相连由电路决定。
- 为保留已使用设计的电气对应，仍采用原有功能字符串作为 pin number / pad number。历史标识 `GND/SWB` 只是兼容用的编号，**不代表手册证明该脚内部接地**。新增符号图内明确标 SWB。
- 手册 pin 5 表内写成 CLX，但 Description 为 CLOCK，本库沿用正确功能名 CLK。

| 手册编号 | 功能 | 保留的电气标识 |
|---|---|---|
| 1 | DAT2 | DAT2 |
| 2 | CD/DAT3 | CD/DAT3 |
| 3 | CMD | CMD |
| 4 | VDD | VDD |
| 5 | CLOCK | CLK |
| 6 | VSS | VSS |
| 7 | DAT0 | DAT0 |
| 8 | DAT1 | DAT1 |
| 9 | SWA | CD/SWA |
| SW B | 检测开关另一端 | GND/SWB |
| SHELL | 金属外壳固定焊脚 | SHELL（8 处共用） |

## 尺寸计算与视角

俯视载板焊盘：卡口朝 +Y（下方），DAT1 在信号排左侧，SWA 在右侧；不能照搬手册右上角器件底视图的左右关系。原点设在外形包络中心，推荐布局图后缘为 y=-5.625 mm，x=0 为推荐布局图红色基准线。

- 外形宽 11.35、深 11.25、高 1.32 mm。F.Fab 按原厂俯视图矢量还原外轮廓，保留卡口斜边与中央浅弧，不描画内部冲压细节。卡插入后露出 3.90 mm、宽 11.00 mm，在 F.SilkS 和 Dwgs.User 以虚线标示露出部分；不切割载板，无 Edge.Cuts。
- 信号 1…8：x=3.20−(编号−1)×1.10，中心 y=(8.35+9.70)/2−5.625=3.400 mm，焊盘 0.75×1.35 mm。原 DAT1 的间距存在 1.08 mm 漂移，现统一为 1.10 mm。
- SWA：x=4.20，y=3.400，宽 0.65、高 1.35 mm；不是旧封装的 0.75 mm 宽。
- 后侧外焊盘：总宽 11.95、内缘距 9.80，因此单侧宽 (11.95−9.80)/2=1.075，中心 x=±5.4375；y 区间为 0…1.05。
- 后侧内焊盘：左 x=-4.50…-3.10，右 x=2.30…3.70，故中心为 -3.80/+3.00，宽 1.40；y 区间为 0…1.05。旧右内焊盘中心约 +3.79，现修正为 +3.00。
- SWB：x=4.95…5.975，y=2.40…3.55；中心 x=5.4625，尺寸 1.025×1.15 mm。
- 左侧壳焊盘 x=-5.975…-5.36，右侧壳焊盘 x=5.25…5.975。两处高度 1.20 mm，左上缘 y=4.15，右上缘 y=4.85。
- 卡口两侧壳焊盘：左 x=-5.975…-4.35，右 x=4.19…5.975，y=10.05…11.55。因此尺寸分别为 1.625×1.50、1.785×1.50 mm，不能使用旧版统一 2.00×1.60 mm。

上述 y 区间均相对推荐布局图后缘，生成时统一减 5.625。左右外缘 ±5.975 按 11.95 对称基准重建。PDF 绘图坐标有约 0.01 mm 的量化偏差，以尺寸链为准。**左侧壳焊盘高度 1.20 mm、卡口焊盘上缘 10.05 mm 没有单独文字尺寸**：从 PDF 矢量直线端点以已标 7.70 mm 尺度还原后归整，记录为图形推导值，不能称为独立标注尺寸。

矩形电气焊盘采用 roundrect，圆角半径为 min(短边×0.25,0.25 mm)。铜、阻焊和锡膏为对应顶层；无 EP 或额外锡膏窗。

## KEEP OUT 与丝印

按用户要求合并为一个矩形 F.Cu 规则域，采用手册中央阴影区域：x=-5.28…5.25、y=1.70…6.90（相对后缘），尺寸 10.53×5.20 mm。禁止顶层走线、过孔和铜皮，允许焊盘和封装；不再按焊盘切成小矩形，也不保留两侧延伸条。信号焊盘及其出线区域位于矩形之外。

这是用户选择的简化范围，并非手册全部阴影区域的逐段复刻；侧边金属下方仍需避免裸露铜。没有设置阻焊开窗或 PCB 挖空。

功能丝印放在卡座内部，DAT3、SWA 使用短名称；SWB 靠近右侧焊盘标识。外侧轮廓在焊盘附近断开，丝印笔画与推荐铜焊盘预留至少 0.20 mm。卡口箭头指向插入方向。卡口浅弧由 PDF 端点及中点拟合，丝印向外偏移 0.20 mm 并避让焊盘；边缘丝印向外偏移 0.15 mm。插卡轮廓下方保留圆角（R0.8 mm 由图形推导，非独立标注公差尺寸），虚线采用 0.6 mm 线段 / 0.4 mm 间隙。只绘制座子外露出的卡片边界，不将遮蔽部分画成实际座子外框。

## 验证与现有设计

- 18 个物理焊盘、11 个独立电气标识；与符号 pin number 集合完全一致。
- 重新导出符号和封装，检查文本、图层和闭合检测开关示意。
- 本次几何有实质变化，已有 PCB 从库更新后应重新检查原走线连接、壳焊脚位置和新禁布区；仅同名引用不会自动使旧实例变为新几何。
