# SHT3x-DIS 4+2 排针模块

根据用户的正反面照片与原理图绘制。分类 `3rd.module.sensor`；符号 `SHT3x-DIS_4Plus2`；封装 `SHT3x-DIS_4Plus2_PinHeader_P2.54mm_13x10mm_Provisional`。板厂未知，不以芯片厂商作为板厂前缀；未限定为未经确认的 SHT30/SHT31/SHT35 具体档位。

## 顶视引脚

传感器朝上、VIN 在左上。背面照片的 AL/A0 在左下，翻回正面后对应右下的 ALERT/ADDR；上 ALERT、下 ADDR。

| 功能焊盘 | x / mm | y / mm |
| --- | ---: | ---: |
| VIN | -5.08 | -3.81 |
| GND | -5.08 | -1.27 |
| SCL | -5.08 | 1.27 |
| SDA | -5.08 | 3.81 |
| ALERT | 5.08 | 1.27 |
| ADDR | 5.08 | 3.81 |

符号引脚编号与焊盘都采用功能名称，不混用芯片引脚号和两组连接器编号。按用户原理图：ADDR 经 10 kΩ 下拉，默认地址 0x44；拉高为 0x45。VIN 直接连接传感器供电，SCL/SDA 经 10 kΩ 上拉至该供电，图中没有 LDO 或电平转换。未将此前 VL53L0X 板的电气特性套用到本板。

## 机械估算

照片未提供机械标注。沿用用户要求的 2.54 mm 网格，纵向孔距为 2.54 mm，两列中心距由照片比例取 10.16 mm（4 倍）。按纵向孔距比例估算外形约 13×10 mm，板框居中，四角暂取 R0.3；列距、板边距和板框需实物核对。焊盘 1.8 mm、钻孔 1.0 mm 为常规排针设计选择；VIN 为圆角矩形，其余为圆形。

安装孔按照片估算为中心 (3.7,-2.5)、直径 3.4 mm，仅作 F.Fab 圆标记。没有在底板钻孔，也没有 Edge.Cuts。芯片外形仅作 F.Fab 位置示意。模块位于底板上方，功能丝印均置于轮廓内部。

## 验证

符号宽 25.4 mm，引线 7.62 mm；功能编号字号 1.0 mm，最长 ALERT 的引线需求为 ceil_grid(5×0.65+2.54)=7.62 mm。引脚与焊盘集合均为 VIN/GND/SCL/SDA/ALERT/ADDR。符号和封装已通过 KiCad SVG 导出及预览检查，全库链接检查通过。
