# mikroBUS 接口

2026-10-10 按用户最新要求，以官方手册规定的标识为准，替代此前正面全部横排及底座轮廓随模块长度拉长的方案。

依据：[MIKROE mikroBUS v2.00 官方 PDF](https://download.mikroe.com/documents/standards/mikrobus/mikrobus-standard-specification-v200.pdf)，本地副本 `mikrobus-standard-specification-v200.pdf`。第 6–9 页为底座规定，第 11–12 页为模块规定。

## 条目及使用

归入 `3rd.connector`：两种符号 `mikroBUS_Socket`、`mikroBUS_Module`，各自默认 S 型封装，另可选择 M/L。

| 规格 | 底座封装 | 模块板框封装 |
|---|---|---|
| S | mikroBUS_Socket_S_2x08_P2.54mm | mikroBUS_Module_S_25.4x28.6mm |
| M | mikroBUS_Socket_M_2x08_P2.54mm | mikroBUS_Module_M_25.4x42.9mm |
| L | mikroBUS_Socket_L_2x08_P2.54mm | mikroBUS_Module_L_25.4x57.15mm |

底座三种规格共用官方尺寸的接口丝印，S/M/L 差异体现在 F.Fab 模块投影及 courtyard 空间预留，并非三种官方电气接口。底座无 Edge.Cuts；模块封装的 Edge.Cuts 是制作模块自身 PCB 的真实板框。

旧 `mikroBUS_Socket_2x08_P2.54mm` 已迁移为 `mikroBUS_Socket_S_2x08_P2.54mm`；已有设计需要更新库引用。

## 实现值与边界

- 底座孔径 1.0 mm 是常用排母安装值，具体型号需核对；排母本体丝印标称 2.54 × 20.32 mm。
- 按此前用户要求，全部焊盘为直径 1.7 mm 的圆形通孔焊盘，无额外首孔分隔标识。手册示意图有方形首孔，但没有规定焊盘形状必须为方形。
- 底座丝印圆角半径 R2.54 mm 是实现值：手册图示圆角但没有独立标注半径。模块实际板框按图采用直角加右下防呆倒角，不添加独立小斜线。
- 原点为 AN 孔中心。模块 x=-1.27…24.13 mm，下沿 y=21.59 mm；末排 GND 孔到下沿 3.81 mm 是现有实现偏移，PDF 未单独标注这一距离。没有将其描述为官方明确标注尺寸。
- 模块排针在板底，B.SilkS 为 U 形本体轮廓，靠板边的一侧省略避免越界；完整本体在 B.Fab。顶部焊接孔仍有 F.SilkS 引脚功能标注。
- 通用模板无法预先知道实际电路：使用时将 BOARD_NAME 改为板名，将未使用引脚的丝印改为 NC，特殊功能按真实电路标注。底座可在标准名称旁增添主板端口名；多个底座的编号需在实际 PCB 中按顺时针安排，REF** 是参考标号占位。不得把这些占位当作已完成的具体模块丝印。
- 电源图标、元件用途标签和适用的认证标记是手册可选项。通用接口不能确定实际模块使用 3.3 V、5 V 或两者，因此不预印电源声明或认证标志，也不标注 click 商标。
- courtyard 是装配空间参考，不是完整电气禁布区；模块底面的实际器件高度需在具体设计中考虑。本库不表示 MIKROE 认证。

## Logo 来源与复现

`mikrobus-logo-contours.json` 保存官方 PDF 第 7 页黑色 Logo 的矢量轮廓（排除红色说明线），贝塞尔曲线分段采样。`scripts/update_mikrobus_standard.py` 将轮廓按奇偶填充转换为不超过 0.02 mm 步长的 KiCad 填充多边形条带，保留字母内部空白；背面图形作水平镜像。没有用相似字体重新拼字。

## 电气对应

| 焊盘 | 底座/主机名称 | 模块名称 |
|---|---|---|
| 1 | AN | AN |
| 2 | RST | RST |
| 3 | CS | CS |
| 4 | SCK | SCK |
| 5 | MISO | SDO |
| 6 | MOSI | SDI |
| 7 | +3.3V | 3V3 |
| 8 | GND | GND |
| 9 | GND | GND |
| 10 | +5V | 5V |
| 11 | SDA | SDA |
| 12 | SCL | SCL |
| 13 | TX | RX |
| 14 | RX | TX |
| 15 | INT | INT |
| 16 | PWM | PWM |


编号仍一一对应，UART 和 SPI 名称相对主机／模块的方向不同，不交换焊盘。所有符号引脚为 passive。

已检查本地库关联、96 个焊盘形状和坐标，并用 KiCad CLI 导出六种封装正背面，预览在 `docs/previews/mikrobus/`。

横排文字对齐：按用户确认参照官方示意图风格，左列左对齐、右列右对齐，正反面分别按各自观察方向处理。锚点位于排针中心向内 2.0 mm，距 2.54 mm 本体边线 0.73 mm；背面同时使用镜像与相反的存储对齐方向。模块正面竖排文字保持居中。这是排版选择，手册未以文字强制规定对齐方式。

模块正面竖排文字进一步靠近排针：文字中心距对应孔列 1.80 mm（x=1.80/21.06 mm），字号仍为 0.65 mm。按文字横向半宽 0.325 mm、线宽半宽 0.06 mm 与焊盘半径 0.85 mm 计算，名义铜边间距约 0.565 mm；正面竖排与背面对齐方式不变。

板名绑定：`mikroBUS_Module` 符号及 S/M/L 封装都有隐藏自定义字段 `BoardName`（默认 `BOARD_NAME`）。正面底部为独立丝印文字 `${BoardName}`，标准 Value 隐藏于 F.Fab。修改原理图符号属性中的 BoardName，再按 F8 从原理图更新 PCB，即同步显示；已有符号需从库更新或手动新增同名字段，已有 PCB 封装需从库更新一次以获得变量文字。字段名大小写保持一致。较长板名需检查实际丝印宽度。

模块 S/M/L 的 Reference 已隐藏，保留字段用于关联；底座 Reference 继续显示。
