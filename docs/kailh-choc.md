# 凯华 Choc 直接焊接轴体

新增 `3rd.switch:Kailh_PG1350`、`3rd.switch:Kailh_PG1353` 两个常开瞬时开关符号，各自绑定同库 `_Solder` 封装。电气引脚均为 1、2（passive），安装孔不编号。不含热插拔轴座、独立 LED 或卫星轴。

## 尺寸与方向

坐标单位 mm，原点为轴心，顶视图 LED 朝上；器件安装在载板正面，外轮廓用 F.SilkS/F.Fab，无载板 Edge.Cuts。

| 项目 | PG1350 / Choc V1 | PG1353 / Choc V2 |
| --- | --- | --- |
| 本体边界 | 15×15 | 15×15 |
| 1 脚中心 | (0, 5.9) | (-5, 3.8) |
| 2 脚中心 | (-5, 3.8) | (0, 5.9) |
| 焊接孔 | Ø1.2 PTH，铜焊盘 2.0 | Ø1.2 PTH，铜焊盘 2.0 |
| 中心安装孔 | Ø3.4 NPTH | Ø5.0 NPTH |
| 定位孔 | (±5.5, 0)，Ø1.9 NPTH | (5, -5.15)，1.5×2.0 椭圆 NPTH |
| LED 中心参考 | (0, -4.70) | (0, -4.93) |

厂家图纸为 Pattern Side。先镜像 X，再旋转到 LED 朝上：PG1350 的图纸坐标转为 KiCad `(x,y)=(-Y,-X)`；PG1353 转为 `(x,y)=(Y,X)`。因此两个版本触点位置相同，但按各自厂家编号，1/2 对调。开关无极性，原理图与各自封装仍严格对应。

- [PG1350 原厂图纸](https://www.kailhswitch.com/Content/upload/pdf/202215927/CPG135001D01-16.pdf)，2021-11-25，首页尺寸图；本地 `Kailh-PG1350.pdf`。
- [PG1353 原厂图纸](https://www.kailhswitch.com/Content/upload/pdf/202015927/PG135301D03.pdf)，2019-10-25；本地 `Kailh-PG1353.pdf`。
- [PG1353 系列兼容孔型图纸](https://www.kailhswitch.com/uploads/15927/files/CPG1353S01D01-01-data-sheet.pdf)，2023-05-12，首页注明定位孔采用 2×1.5 形状以兼容该系列；本地 `Kailh-PG1353-Silent-2023.pdf`。采用此孔型替代早期 Ø1.6 圆孔。两份 PG1353 文件标题均标“临时版”；最终生产仍应核对实际订购型号。

轮廓表示外形包络，未臆测内部卡扣尺寸。丝印 Reference、型号和引脚数字放在本体范围内；LED 位置仅在 Dwgs.User 标识，未将独立 LED 或光窗孔混入轴体电气封装。键帽大小与键距由键盘布局决定，本封装未固定 1u 键帽边界。
